# DSH 压缩替换包（重建 / 移植）

**一句话**：**配置放 profile 根（volatile）→ 引擎放预设隔离组（只提供 `compaction`）→ 覆盖层按目标机 DSH 版本现场生成 → 四级验证。**

产物：一个 bundle 包 `@dsh-external/dsh-compaction-pack`，装进 profile 后在插件页多一张「压缩调参」卡片，并把 `standard` 预设里的 `compaction-basic` 换成新引擎。

## 何时用

- 压缩一次吞掉几十万 token、只留一条十几 KB 摘要，关注点漂移、原话/纠正/证据链丢失。
- 想不重启就改阈值、保留量、摘要路由、检查点 prompt。
- 要在另一台机器上复现同一套，不想依赖 zip 或网络。

## 四条硬约束（违反任意一条都会白干）

1. **压缩服务在预设的隔离组里**。`presets/standard.patch.yml` 的 `compaction` 组声明 `isolate: { compaction: true }`；Cordis 隔离域**不回退**到父域（`vendor/cordis/src/context.ts` 的 `isolate`）。所以 profile 根挂的 `compaction` 提供者，组内看不到；引擎必须写进预设的插件列表。
2. **settings 只为 profile 条目生成表单**。`ctx.settings.describe()` 遍历 `configEditor.configuration()`（profile 条目）；预设内的行不是 profile 条目，`.volatile()` 也不会出现在卡片里。所以**可调配置必须放在 profile 根的一个插件里**，预设内只放读它的薄引擎。
3. **Loader 对 `config` 是整体替换，不按 id 深合并**（`vendor/loader/src/config/entry.ts` 的 `Entry.update` 逐 key 赋值）。覆盖 `preset-standard` 必须重述完整 `config`（`id` / `order` / 完整 `plugins`），否则预设丢字段。
4. **客户端半是 `window.__ModuleLoader__.load({ id, factory })` 形态**，`factory` 收到的 `require` 只能解析 baseline 模块（`react`、`@deepseek-ai/dsh-client-ui-primitives`、`dsh-client-store` 等，见 `packages/client/web/src/platform.ts` 的 `PLATFORM_MODULES`）。ESM `import` 语句在这里不工作。

## 落地六步

1. **复制源码**：`references/files/` 下 4 个 Host 源文件（engine/tuning/prompt/index）+ `lib/client.js` + 4 个 tools 脚本 + `package.json`，按同名放到包目录。
2. **打包 Host 半**（`@deepseek-ai/*` 全部外置，只打包自有代码）：

   ```powershell
   $esbuild = "<dsh-checkout>\node_modules\.bin\esbuild.CMD"
   & $esbuild src/tuning.mjs --bundle --format=esm --platform=node "--external:@deepseek-ai/*" --outfile=lib/tuning.js
   & $esbuild src/engine.mjs --bundle --format=esm --platform=node "--external:@deepseek-ai/*" --outfile=lib/engine.js
   & $esbuild src/index.mjs  --bundle --format=esm --platform=node --outfile=lib/index.js
   ```

   **不要把 `@deepseek-ai/*` 打进 bundle**：workspace 的 `lib/*.js` 含装饰器语法会让 esbuild 直接产出无法解析的文件；`cordis` 的 `Service` 身份也必须与宿主同一份。
3. **建依赖联接**：`node_modules/@deepseek-ai` → 该机 DSH 的 `node_modules/@deepseek-ai`（profile 自己的 `node_modules` 只有已装 bundle，DSH 包在 **profiles 根**）。`tools/install.ps1` 已实现并会自动挑路径。
4. **生成覆盖层**：`node tools/gen-patch.mjs [<dsh-web-app>/presets/standard.patch.yml]`。它把随包预设原文逐字复制，只把 `compaction` 组里的 `- id: compaction-basic` 两行换成 `- id: compaction-engine` + `name: '@dsh-external/dsh-compaction-pack/engine'`，再追加两条根行。**DSH 升级后必须重跑**。
5. **安装**：插件页 →「添加插件」选包目录（或 `dsh plugin add <目录>`）。装完 `application: applied`。
6. **新开会话验证**（见下）。已有会话保留它启动时的预设版本，不会变。

## 四级验证

| 级别 | 命令 / 位置 | 期望 |
|---|---|---|
| 组合 | `dsh --profile <p> --dump-config` | `# == @dsh-external/dsh-compaction-pack` 段里 `preset-standard` 的 compaction 组是 `compaction-engine` |
| 挂载 | 起一个新会话（或跑一次 subagent） | 会话能正常开始；预设挂载失败会直接起不来 |
| 设置 | `cordis_inspect_query` Config → 条目 `compaction-tuning` | 状态 `schema`，13 个字段都带 `x-cordis.volatile` |
| 客户端 | `cordis_inspect_query` client Slots → `plugins.item` | `compaction-pack` 在 occupant 列表里且 `active: true` |

另有两个离线自检：`node tools/selfcheck.mjs`（Host 半 + 补丁）、`node tools/client-smoke.mjs`（客户端半装配）。

## 踩过的坑

| 现象 | 根因 | 处置 |
|---|---|---|
| `preset-standard` 覆盖后预设缺 `id`/`order` | Loader 对 `config` 整体替换 | 覆盖层必须重述完整 config |
| 卡片不出现 | 只给预设内的行加了 volatile | 配置挪到 profile 根插件 |
| `Invalid or unexpected token ... @Remote` | 把 workspace `lib/*.js` 打进 bundle | 外置 `@deepseek-ai/*` |
| 装完设置改了不生效 | 引擎在构造时把配置深拷贝冻结 | 引擎每次决策读 `tuning.snapshot()`（volatile ref 就地更新） |
| `install.ps1` 找不到 cordis | 默认指向 profile 的 node_modules | 指向 `profiles/node_modules/@deepseek-ai`（脚本已按候选顺序探测） |
| `/compact` 仍然一次性全压 | 继承的 `compactNow()` 用 retain 0 | 已知限制：靠阈值自动触发，别按 `/compact` |
| 用 Web 预设编辑器改过 `standard` 后引擎消失 | Web 把完整 `config.plugins` 写进 profile 层，优先级高于 bundle | 重跑 `gen-patch.mjs` 重装，或在 Web 里把该行改成 `@dsh-external/dsh-compaction-pack/engine` |

## 移植格式（重要）

本机 DLP 会按扩展名加密 `.md`（实测：`.md` 的 `:$DATA` 比明文长 4096 字节；`.txt`/`.js`/`.mjs`/`.json`/`.yml`/`.zip` 无开销）。因此：

- 本 skill 的 `.md` 只用于**本机加载**；跨设备请传 `SKILL.txt`、`references/*.txt`，或整个 skill 的 zip（zip 内是明文）。
- 到目标机后把 `.txt` 改名回 `.md` 即可加载；源码文件（`references/files/*`）本身就是明文，直接复制。
- 压缩包目录里同理：`README.txt` 是明文版，`README.md` 仅供本机阅读。
